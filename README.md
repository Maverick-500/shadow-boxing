# hoi

Acchi Muite Hoi, the Japanese pointing game, against a machine that reads you.

You turn your head left, right, up or down and it points. The pointer wins on a
match, so the honest ceiling for a player is one in four. The game is not about
winning exchanges: it builds a model of your habits while you play, stops and
names the habit it is using against you in a sentence you can check, and then
asks you to push its read on you back down and hold it there.

Live at https://telegraph-hoi.vercel.app

Built for the Haven Sydney 24 hour jam, 14 to 15 November 2026.
